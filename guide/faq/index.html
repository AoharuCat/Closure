常见问题

和普通聊天工具有什么不同？

章节「和普通聊天工具有什么不同？」

Closure 为同一个长篇项目持续保存结构、设定、材料与版本历史。AI 写章时参考这些上下文，检查点和修订对比让你参与判断。它需要作者提出创意和取舍，不承诺一句话自动完成一本可出版小说。

免费吗？需要账号吗？

章节「免费吗？需要账号吗？」

应用开源，可以免费使用本地工作区，无需 Closure 云端账号。模型 API、搜索与其他第三方服务可能收费，需要自己的凭据或额度。预算面板的估算不替代服务商账单。

稿件只存在本地，就不会联网吗？

章节「稿件只存在本地，就不会联网吗？」

章节、大纲与设定以普通文件保存在项目文件夹里。在线模型会接收完成任务所需的请求上下文，联网研究和在线导入也会访问外部服务。请按模型供应商的数据政策与自己的材料要求选择功能；保存版本节点本身不会上传稿件。

为什么下载到 macOS 或 ARM64 后仍可能出问题？

章节「为什么下载到 macOS 或 ARM64 后仍可能出问题？」

公开发行版有这些附件，但 macOS 未签名、自动更新不可用，ARM64 尚无真机验证。三平台 CI 与启动冒烟不能覆盖所有设备上的完整创作流程。参见安装限制。

生成失败后怎么处理？

章节「生成失败后怎么处理？」

先查看当前错误、模型连通性、额度和已保存内容。认证、超时、预算阻止与模型无有效输出应分别处理；不要反复启动相同的长任务。需要反馈时记录触发步骤和版本号，并移除密钥及私人稿件。

同人专用管线已经完成了吗？

章节「同人专用管线已经完成了吗？」

尚未。原作理解、角色锚点、受控偏离和 OOC 专门审核仍在公开路线图中。现有材料库、设定、结构和通用审核可用于创作准备，但不能等同于完整同人专用流程。

如何反馈问题或贡献？

章节「如何反馈问题或贡献？」

在公开 Issues提供复现步骤、预期与实际行为、操作系统和应用版本。若包含安全漏洞，遵循 SECURITY.md 的私密报告渠道。贡献入口见开发者文档，许可与第三方归属见 LICENSE 和 NOTICE。
