模型配置

Closure 使用你自己的模型服务与额度。公开版本支持 OpenAI / Anthropic 兼容端点，也提供 Antigravity CLI 通道。不同供应商的字段、能力和计费并不完全相同。

先连接一个可用模型

章节「先连接一个可用模型」
  1. 在设置的模型配置区域添加供应商与端点，填写该服务提供的 API 密钥。
  2. 按供应商文档核对基础 URL 和模型标识。不要把网页聊天地址当作 API 地址。
  3. 保存后测试连接或进行一次短对话；确认认证、额度与返回内容正常。
  4. 需要图片识别时选择具备视觉能力的模型。嵌入、重排和生图也需要相应能力，不能只凭模型名称判断。

API 密钥在本地加密保存。不要把密钥粘贴到 Issue、截图、文档或公开项目文件里。

按任务分工

章节「按任务分工」

规划、正文写作、审核、研究与风格分析可分别指定模型和思考档位。先用稳定配置跑通一章，再按质量与成本调整。公开 v0.4.0 支持把整组指派保存为预设，便于切换。

可配置回退模型：主模型遇到额度、认证、超时或网关错误时，应用会尝试回退并提示来源。熔断会暂时跳过短时间连续失败的模型，稍后探测恢复。回退不等于质量相同，仍需检查输出。

用量与预算

章节「用量与预算」

用量页记录本机调用，按模型和任务分解 token、耗时、失败与估算费用。v0.4.0 加入月度软/硬预算；达到硬线后会阻止新调用。估算费用与供应商账单可能不同，保留窗短于一个月时月度统计只覆盖已保留记录。

CLI 通道与排错

章节「CLI 通道与排错」

Antigravity CLI 需要独立安装、登录及应用内配置。按应用中的连接状态和授权提示操作；工具能力与限制会随版本变化，尤其注意 v0.3.2 与 v0.4.0 的差异。

连接失败时依次核对 URL、模型名、凭据、配额和供应商状态。自定义请求头或额外请求体只在服务明确要求时填写。使用在线模型、搜索或材料导入会向相关服务发送请求；本地存储不等于模型推理永不联网。

依据：公开 README 与 v0.4.0 发布说明。
