v0.4.0 · 后台协作与月度预算

2026-09-22 (UTC)GitHub 原始发布说明 ↗全部版本

历史发布记录：功能与限制描述的是该版本发布时的状态。 正文来自原始发布说明。

本版把「多智能体」补成 Closure 的一条主线：对话中的 AI 可以把任务交给后台子代理并行执行，主对话零中断、随时可看可停。配套地，材料库可以直接在线导入（wiki 词条、批评文章），用量台账补齐全调用面并新增月度预算，模型网关获得熔断保护与整组预设。

新功能 / New Features

  • Agent 面板：后台子代理——对话中把调查/长任务派给后台子代理并行执行（每项目至多 3 个），主对话不中断；「后台任务」条实时显示状态与耗时，可取消、可点开只读检视子会话完整过程
  • Agent 面板：子代理结果三通道——完成时弹通知、自动唤醒主对话汇报、或静默记账，派发时任选；应用重启后未完成的任务如实标注「已中断」
  • 材料库：在线导入——URL 直贴或关键词搜索（萌娘百科等 wiki 词条、批评文章页），自动抽取正文、按来源（社区/原作/批评）预填出处，同链接重复导入幂等
  • 手艺卡：讲法来源徽章——蒸馏产出的讲法在人审页标注来自社区 wiki、原作还是批评文章
  • 用量面板：全调用面计量——嵌入/重排/生图调用入账并按任务标签分账（知识库检索/索引/生图等），生图行显示张数；Antigravity CLI 重试与降级逐次尝试记账，不漏不重
  • 用量面板：月度预算——设置软/硬双线（¥），面板显示月度进度与状态色，过线一次性提醒；触及硬线时新调用被拦并如实入账
  • 模型配置：任务档多套预设——整组模型指派一键保存/切换/删除，当前状态显示预设名或「自定义」
  • 模型网关：熔断保护——同一模型短时间内连续失败自动进入冷却跳过，回退链不再反复撞死端点；冷却结束自动探针恢复
  • Antigravity CLI：桥车道工具能力对等——桥会话内可调用 Closure 的本地写作工具（读文件、检索、写章等），工具失败如实呈现

修复 / Fixed

  • Agent 页：CLI 模型徽标与桥授权状态矛盾修正——授权后显示「CLI · 工具经 MCP 桥」
  • 桥会话：隔离假宿不再复制 CLI 历史日志（防体积膨胀与隐私泄漏）
  • 设置：对话框打开期间的校验提示不再被遮罩盖住
  • Agent 面板：桥警示条随回合结局收敛——被纠正续跑救回的成功回合不再挂着「离开写作工具族」警示
  • 版本管理：并发提交串行化保护——多任务同时提交版本不再互相孤儿化
  • 用量面板：保留窗不足一个月时，月度累计如实标注「仅覆盖近 N 天」

已知限制 / Known Issues

  • 后台子代理、在线导入、月度预算已过全量自动化测试，完整真机验收进行中；遇到问题请提 issue
