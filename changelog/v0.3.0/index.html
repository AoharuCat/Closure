v0.3.0 · 写作页全程时间线

2026-09-18 (UTC)GitHub 原始发布说明 ↗全部版本

历史发布记录：功能与限制描述的是该版本发布时的状态。 正文来自原始发布说明。

v0.2.0 之后的一次大更新：写作页全面改版——写章全程一条时间线，审批和终稿都在写作页就地完成；同时新增 Antigravity CLI 接入、模型自动回退链和应用内用量面板。

新增

  • 写作页全面改版：写章从对话栏发起后，AI 的思考、调查、工具调用、正文流在写作页全程时间线可见；规划与终稿的审批卡就地处理；终稿可直接手改，也可以选中文字让 AI 精修。
  • Antigravity CLI 接入：新增通过 Antigravity CLI（agy）接入对话模型——经 Google 官方通道直连调用 Gemini 系列模型，不经第三方反代中转，密钥与请求数据不经他人之手；订阅配额内成本远低于按 token 计费的 API。配合工具桥，对话模型可在一次性授权后调用 Closure 的写作工具（写章、查设定、资料检索）。
  • 模型自动回退链：设置页可为任务档位配置回退模型——主力模型失败（配额 / 认证 / 超时 / 网关）时自动切换并在对话中提示，消息带「回退自」标记。
  • 用量面板：设置页新增「用量」页：本机调用量的本地计量——按模型 / 按档位分解、估算费用、失败与耗时一目了然；记录按保留窗自动清理，另附官方网页配额外查。
  • 自定义请求头与默认参数：模型配置支持自定义请求头（网关鉴权 / 自建路由）、模型默认参数与额外请求体字段（厂商长尾参数逃生舱）。

改进

  • 拆书引擎一批修复：43 万字真书实测后集中修复——长输出截断自动升帽重试、失败任务可重跑、派生 .md 章标记保全、重新摄取不再显示 0 章假态。
  • 对话前缀缓存：对话链路接入前缀缓存，长对话中重复的上下文不再每次全价重算，更快也更省。
