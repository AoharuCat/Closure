Changelog

A record of how Closure grows. These notes preserve each release’s original context; older limitations may have changed in later versions.

  1. 2026-09-22

    v0.4.0 · Background collaboration and monthly budgets

    Background sub-agents, online material import, full-call metering, and model presets. Complete real-machine verification remains in progress.

    Read the release notes →
  2. 2026-09-19

    v0.3.2 · A more reliable CLI integration

    In-project search, better diagnostics, and fixes for silent failures. The CLI in this version cannot dispatch the writing chain or planners.

    Read the release notes →
  3. 2026-09-19

    v0.3.1 · Build and startup checks across three platforms

    Cross-platform CI and startup smoke, safer file operations, and encoding fixes. macOS is unsigned; ARM64 has not been tested on physical hardware.

    Read the release notes →
  4. 2026-09-18

    v0.3.0 · A complete writing timeline

    Follow drafting, approvals, and final prose in one writing view, with a CLI channel, model fallback chains, and usage reporting.

    Read the release notes →
  5. 2026-09-06

    v0.2.0 · From materials to book analysis

    Import works, analyze style and setting, and retain style and craft cards after human review.

    Read the release notes →
  6. 2026-08-30

    v0.1.1 · World state and settings panels

    New world-state and settings views, with fixes for suspended writing chains, first-chapter startup, and preload failures.

    Read the release notes →
  7. 2026-08-29

    v0.1.0 · The first public release

    A local writing workspace with story structure, cognition, world events, and controlled revision.

    Read the release notes →
